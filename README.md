# Issue Tracking and Resolution Dashboard

A React + JavaScript single-page dashboard for tracking issues through predictable resolution stages.

## Features

- Overview dashboard with issue metrics, searchable listings, and status indicators
- Reusable issue cards, detail panels, filters, and summary widgets
- Controlled issue creation form with state-driven updates
- Route-based navigation for overview, pipeline, and create flows
- Mock asynchronous loading and issue status transitions with loading/error states
- Memoized derived lists and accessible form and button controls

## Tech Stack

- React 18
- React Router
- Vite
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
